# Intra Prediction Mode Analysis (IPMA)
This project provides an engine to perform Intra Prediction Mode Analysis on raw YUV 4:2:0 video sequences. It simulates spatial intra-coding, calculates quality metrics, and generates a heatmap visualization.

## Prerequisites
+ Google Colab account
+ intra_codec_analyzer.ipynb
+ Datasets

### Setup Instructions
+ Open Google Colab. Click File -> Upload Notebook -> Browse -> intra_codec_analyzer.ipynb
+ Create Datasets folder. Download a title_qcif.y4m file (e.g. akiyo_qcif.y4m) from:
